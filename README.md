This project involves the production of a simple web application. I chose to create a simple mpc drone tuner which the user can interact with and change the gains to influence drone trajectory. 
This project uses Google's Firebase as its main database.
Users can save their parameters and previous runs. They can also delete runs and load runs as well. The simulator also has a disturbance button to simulate wind gusts and other small features for the user to explore.
Overall this simulation aims to help those unfamiliar with modern predictive control better understand what it does and what it can look like in 3D space.

*Please note this is software was made by using Copilot to iterate upon an .html script. This project was inspired by my senior design II project for the autonomous drone application.
